===== PAGE 파일마스터(PileXY) 구축·현장 적용(안) =====
# 배경 및 목적
1) 말뚝 3~4천 본 위치 확인에 1주일 이상 소요, 오류 시 오시공 → 마이크로파일·철근 보강
2) 설계·시공실적·드론 측량이 나뉘어 차이를 한눈에 보기 어려움
3) 말뚝 중심점 자동 산출로 5~10분 내 정합성 확인, 지반개량(GEO.D)도 동일 적용
# 추진계획
1) 주관: 건축BIM팀 자체 개발  /  청주씨엘리체 적용중  (PoC 청주센텀푸르지오자이·풍무역푸르지오더마크 완료)
2) 단계: ① 자체 PoC  ② 현장 적용  ③ 본부 확대
3) 항목: 좌표 정합성, PDAM 항타, 메이샤 드론, 지적·이격, 공구별 시공 시뮬레이션, 기성·자재
- 3~4천 본 중심점 자동 산출 (1주일 이상 → 5~10분) | - PDAM 항타 길이·관입 · PHC 시공길이 대조 | - 드론 정사 ↔ 시공현황 겹침 · PDAM 연동
- 대지경계 정합 · 흙막이-말뚝 이격 파악 | - 업체·공구별 시공 순서 · PDAM 사전 시뮬 | - 업체별 입고·시공 · 높이별 기성 자동
# 향후계획
1) 현장 → 현장기술지원 → 건축BIM팀 접수 후 WEB 링크 열람 체계 정착
2) 항타·드론·지적·기성 연동 범위를 전 현장으로 확대
3) 청주씨엘리체 적용 결과를 바탕으로 본부 표준 업무 절차 반영
===== PAGE 배경·업무시나리오 (상세) =====
1) 배경
    ▪ 말뚝 3~4천 본 위치 대조에 1주일 이상
    ▪ 좌표 오류 시 오시공 → 마이크로파일·철근 보강
    ▪ 설계·시공실적·드론이 나뉘어 차이 확인 곤란
2) 목적
    ▪ 말뚝 중심점 자동 산출, 5~10분 내 정합성 확인
    ▪ 지반개량(GEO.D) 도 동일 규칙으로 확인
    ▪ 청주씨엘리체 적용중, PoC 2개 현장 완료
    ▪ 요청 경로  현장 → 현장기술지원 → 건축BIM팀
    ▪ BIM팀 작업 후 WEB 주소로 현장·본사 열람

    ▪ 처리 흐름
1) 적용: 청주씨엘리체 적용중 · PoC 청주센텀푸르지오자이·풍무역푸르지오더마크 완료
2) 효과: 위치확인 1주일 이상 → 5~10분 · 오시공 조기 발견 · 설치 없이 WEB 열람
3) 창구: 현장 → 현장기술지원 → 건축BIM팀 접수 후 수일 내 링크 전달
4) 산출: 말뚝 중심점·정합 결과·WEB 주소 (현장·본사 동일 화면)
5) 주의: 시공도면·동·층 정보 누락 시 접수 지연 - 요청 시 필수 첨부
6) 범위: 좌표 정합·항타·드론·지적 이격·시공 시뮬레이션·기성 자재 (요약 1p 항목과 동일)
7) 확산: 현장 적용 결과를 본부 표준 절차에 반영 후 타 현장 확대
8) 문의: 건축BIM팀 (파일마스터 접수·WEB 링크 발급)
